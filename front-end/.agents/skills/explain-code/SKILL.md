# Explain Code

Leia os documentos relevantes em `.ai/` e inspecione o código citado e seus vizinhos diretos.

Explique do geral para o específico: finalidade, entradas, fluxo, saídas, dependências e tratamento de erros. Separe comportamento observado de intenção documentada. Use exemplos curtos quando ajudarem e aponte onde o código confirma cada afirmação.

Não edite código em uma tarefa somente de explicação. Termine destacando decisões, riscos ou lacunas ainda não definidos.
