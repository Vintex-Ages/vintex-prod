# Contexto do projeto

O Vintex é uma prova de conceito de marketplace de moda circular para brechós e microempreendedores de moda usada, desenvolvido na disciplina AGES no semestre 2026/2 para um cliente real.

Este repositório cobre somente o front-end. Backend, banco de dados e recursos de IA vivem em repositórios ou serviços separados e são consumidos por API REST.

Áreas previstas: landing page, autenticação, catálogo, produto, perfil do brechó, painel do vendedor, administração da plataforma e assistente Vintex.

Restrições conhecidas:

- pagamentos reais estão fora do escopo; somente mock/simulação é previsto;
- identidade visual final ainda precisa ser definida;
- a base está no início da implementação e a arquitetura deve evoluir com decisões registradas, não por suposição.
