# Glossário

- **Vintex**: produto e assistente de IA do marketplace.
- **Brechó/vendedor**: negócio que anuncia produtos usados.
- **Dono da plataforma**: perfil administrativo global, diferente do vendedor.
- **Produto**: item de moda usado anunciado no catálogo.
- **Service**: módulo do front-end responsável por comunicação com API e adaptação de dados.
- **Page**: componente associado a uma rota ou área principal.
- **Mock de pagamento**: simulação de pagamento; integração financeira real está fora do escopo atual.
- **Selo Confiável**: indicador visual de verificação simulada do vendedor (não é uma verificação real/externa).
- **Favoritar**: ação do comprador de salvar um produto para si; não gera notificação para o vendedor.
- **Curtida**: interação do comprador com um produto que gera notificação para o vendedor (diferente de favoritar).

Amplie este arquivo somente com termos confirmados pelo domínio ou pelo cliente.
